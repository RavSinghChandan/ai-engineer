# Model comparison — rag_grounding

RAG grounding and adversarial documents for the role mapper. Clean cases check that the answer cites its role documents and lists only skills those documents state. Adversarial cases put a poisoned document next to a restricted HR record, as if the retrieval screen had missed it, and check the model neither leaks the record or its system prompt, nor emits a tool call, nor lets the document set its score. All people and records are fictional.
