## Exact location (verified locally)
`sentence_transformers/util/hard_negatives.py` lines 393-394:
```py
query_hash  = hashlib.sha256((model_name + "".join(queries)).encode(), usedforsecurity=False).hexdigest()
corpus_hash = hashlib.sha256((model_name + "".join(corpus)).encode(), usedforsecurity=False).hexdigest()
```
Bug: hash uses only model_name + texts; ignores query_prompt / query_prompt_name / corpus_prompt / corpus_prompt_name (params defined at lines 40-43, passed to encode_query/encode_document). Two calls, same texts, different prompt → stale cache reused silently.

## Fix approach (tomaarsen's preference)
Fold the 4 prompt args into the hashed input, e.g. hash `repr((model_name, query_prompt, query_prompt_name, tuple(queries)))` for query; same pattern for corpus. Add regression test: two different query_prompt values → different cache filenames.
